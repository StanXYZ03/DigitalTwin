# 网页版数字孪生按键核心代码

本文只提取 F1～F10 按键数字孪生的 Web 端关键实现，包括浏览器前端和 Node.js 后端，不包含 STM32、FMC 或 FPGA 代码。完整、可运行代码仍以文末列出的源文件为准。

## 1. 控制链路

```text
浏览器 pointerdown / pointerup
        ↓ HTTP POST
Node.js 命令队列（M0KC、CRC16、重发、ACK）
        ↓ UDP 控制帧
硬件设备
        ↓ UDP 遥测（按键状态及 control_ack）
Node.js 状态模型
        ↓ WebSocket
浏览器同步显示实体按键和网页按键状态
```

Web 端负责采集操作、可靠下发和状态显示；Node.js 中的 `keys` 异或只用于生成页面展示数据。

```js
const locallyHeld = new Set();

async function setKey(key, action) {
  const response = await fetch(
    `/api/digital-twin/devices/${device}/keys/F${key}/${action}`,
    { method: 'POST', keepalive: action === 'up' }
  );
  const result = await response.json();
  if (!response.ok) throw new Error(result.error || response.status);
}

function down(button, event) {
  if (button.disabled) return;
  event.preventDefault();

  const key = Number(button.dataset.key);
  if (locallyHeld.has(key)) return;       // 长按期间不重复发送 down

  locallyHeld.add(key);
  button.setPointerCapture?.(event.pointerId);
  button.classList.add('pressed');
  setKey(key, 'down');                    // 鼠标/触摸按下立即发送
}

function up(button, event) {
  const key = Number(button.dataset.key);
  if (!locallyHeld.delete(key)) return;

  event?.preventDefault();
  button.classList.remove('pressed');
  setKey(key, 'up');                      // 松开时发送
}

[...virtualKeys.children].forEach(button => {
  button.addEventListener('pointerdown', e => down(button, e));
  button.addEventListener('pointerup', e => up(button, e));
  button.addEventListener('pointercancel', e => up(button, e));
  button.addEventListener('lostpointercapture', e => up(button, e));
  button.addEventListener('contextmenu', e => e.preventDefault());
});

// 页面失焦时补发 up，避免网络端残留“按住”状态。
window.addEventListener('blur', () => {
  [...locallyHeld].forEach(key => {
    locallyHeld.delete(key);
    setKey(key, 'up');
  });
});
```

```js
if (req.method === 'POST' && keyMatch) {
```

### 3.2 M0KC 控制帧

```js
function crc16Ccitt(bytes, length = bytes.length) {
  let crc = 0xffff;
  for (let index = 0; index < length; index += 1) {
    crc ^= bytes[index] << 8;
    for (let bit = 0; bit < 8; bit += 1) {
      crc = (crc & 0x8000)
        ? (((crc << 1) ^ 0x1021) & 0xffff)
        : ((crc << 1) & 0xffff);
    }
  }
  return crc;
}

function buildControlFrame(key, action, commandId) {
  if (!Number.isInteger(key) || key < 1 || key > 10) throw new Error('key');
  if (action !== 'down' && action !== 'up') throw new Error('action');

  const frame = Buffer.alloc(16);
  frame.write('M0KC', 0, 'ascii');
  frame[4] = 1;                              // version
  frame[5] = key;                            // F1～F10
  frame[6] = action === 'down' ? 1 : 2;
  frame[7] = 0;                              // reserved
  frame.writeUInt32BE(commandId >>> 0, 8);
  frame.writeUInt16BE(0, 12);                 // reserved
  frame.writeUInt16BE(crc16Ccitt(frame, 14), 14);
  return frame;
}
```

16 字节帧格式：

| 偏移 | 长度 | 含义 |
|---:|---:|---|
| 0 | 4 | ASCII `M0KC` |
| 4 | 1 | 协议版本 `1` |
| 5 | 1 | 按键编号 `1～10` |
| 6 | 1 | `1=down`，`2=up` |
| 7 | 1 | 保留，必须为 0 |
| 8 | 4 | 大端 `command_id` |
| 12 | 2 | 保留 |
| 14 | 2 | 前 14 字节的 CRC16-CCITT，大端 |

### 3.3 单飞命令队列与 ACK

```js
enqueue(key, action, now = Date.now()) {
  if (this.pending.length >= 16) throw new Error('queueFull');

  const command = {
    id: this.nextId >>> 0,
    key,
    action,
    createdAtMs: now,
    attempts: 0,
    lastSentAtMs: 0
  };
  this.nextId = (this.nextId + 1) >>> 0;
  if (this.nextId === 0) this.nextId = 1;

  this.pending.push(command);
  this.dispatch(now);
  return command;
}

dispatch(now = Date.now()) {
  if (this.inflight || this.pending.length === 0) return;
  this.inflight = this.pending.shift();       // 同时只允许一条命令在途
  this.send(now);
}

send(now = Date.now()) {
  this.inflight.attempts += 1;
  this.inflight.lastSentAtMs = now;
  this.sendFrame(buildControlFrame(
    this.inflight.key,
    this.inflight.action,
    this.inflight.id
  ));
}

acknowledge(commandId, now = Date.now()) {
  if (!this.inflight || commandId !== this.inflight.id) return false;
  this.inflight = null;
  this.dispatch(now);
  return true;
}

tick(now = Date.now()) {
  if (!this.inflight) return this.dispatch(now);
  if (now - this.inflight.lastSentAtMs < CONTROL_RETRY_MS) return;

  if (this.inflight.attempts < CONTROL_MAX_ATTEMPTS) this.send(now);
  else this.inflight = null;
}
```

设备把最后成功处理的 `command_id` 放入遥测的 `control_ack`。服务端收到遥测后确认当前命令：

```js
if (packet.control_ack) controls.acknowledge(packet.control_ack);
```

服务端还把两类按键状态拆开，并计算一个只用于页面展示的 XOR：

```js
physicalKeys: Array.from({ length: 10 }, (_, i) =>
  Boolean((value.key_state || 0) & (1 << i))),

virtualKeys: Array.from({ length: 10 }, (_, i) =>
  Boolean((value.virtual_key_state || 0) & (1 << i))),

keys: Array.from({ length: 10 }, (_, i) =>
  Boolean(((value.key_state || 0) ^
           (value.virtual_key_state || 0)) & (1 << i)))
```

## 4. exp2-01 网页按键展示

| 网页按键 | 页面名称 |
|---|---|
| F1 | 计数速度（1 s、0.5 s、0.25 s、0.125 s） |
| F2 | 暂停 / 继续 |
| F3 | 清零 |
| F4 | 递减 |
| F5 | 递增 |
| F6 | LED 方向 |
| F7～F10 | 本实验未使用 |

“未使用”只表示 exp2-01 没有给该键分配实验语义，不表示网页删掉按键。F1～F10 的网页按下、松开、设备 ACK、实体状态和网页状态都完整保留。
