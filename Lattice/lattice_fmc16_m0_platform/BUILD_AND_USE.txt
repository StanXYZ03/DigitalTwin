FMC16 M0 精简版 Lattice 工程说明

工程目录：D:\FPGA_prj\lattice_fmc16_m0_minimal
器件：LCMXO2-4000HC-4TG144C
顶层：fmc16_link_test_top
可烧录文件：FMC16_M0_DUALMODE_BUILD_4C4B0007.jed

本版本用途
1. 保留已经验证过的 mini FMC16 异步物理层和 packet/CRC 协议。
2. 保留轻量数据通路，只开放 M0 计数器和 M11 点阵屏两种安全模式，不引入多级缓存、事件队列和通用事务引擎。
3. 稳定采样实验 FPGA 的 PO[31:0] 和 PIO[15:0]。
4. Lattice 对全部 PIO 始终输出高阻，仅观察实验 FPGA 的 PIO，不与其争用。
5. F10 实体按键在 M0/M11 间切换；命令 0x0004 可直接选择 M0 或 M11。F10 只用于平台切换，不送入 Xilinx PI，但仍上报按键状态。
6. M0 中 F1～F9 保留翻转事件编码并映射 PI7～PI15；M11 中 F1～F9 映射 PI0～PI8，并上报消抖后的按住/松开电平，以兼容点阵实验的上升沿检测。
7. Lattice 仅在 NE1 有效且 NOE 有效的 FMC 读周期驱动 FMC_DB[15:0]；访问 SDRAM或 FMC 写周期时全部高阻。

FMC packet 支持
上电发送：RESET_NOTICE -> LINK_HELLO -> DEVICE_INFO。
命令 0x0001：GET_CAPABILITIES。
命令 0x0003：GET_STATUS_SNAPSHOT。
命令 0x0004：SET_MODE，options[3:0] 仅允许 0 或 11，其他 options 位必须为 0。
0x0003 RESPONSE 的 payload 共 14 words：
P0 opcode=0x0003
P1 status=0
P2 detail=0
P3 result_words=10
P4 schema=0x0100
P5 validity：bit0=本地数据有效，bit1=PO 连续采样一致，bit2=PIO 连续采样一致，bit8=FMC_CLK 采样电平，bit9=FMC_NWAIT 采样电平
P6 为请求 PI，P7 为实体 F1～F10 状态，P8[15:12] 为当前模式、P8[11:0] 为按键事件计数
P9 PO[31:16]
P10 PO[15:0]
P11 PIO[15:0]
P12 timestamp_ms[31:16]
P13 timestamp_ms[15:0]

烧录注意
该位流设置 JTAG_PORT=DISABLE，配置后复用 JTAG 脚作为 FMC 用户 IO。烧录时必须按当前硬件方法使 120 脚 JTAGENB 为高，并在必要时拆下过桥板；烧录完成后再按实验连接要求装回过桥板。
STM32 工程已接入 0x0003 状态读取和 0x0004 模式直选；网页只提供 M0 计数器和 M11 点阵屏选择。STM32 在切换时以 break-before-make 顺序自动设置 PCAL6524：M0 全断开，M11 选择 BSW-A/B3（物理拨码 B1、B2、B5、B6、B8、B9 置 ON，B3、B4、B7、B10 置 OFF，对应位图 0x01B3）。

边界说明
模式切换负责平台路由、按键映射和观测口径，不会替换 XC7A100T 内部 bitstream。选择 M0 或 M11 时，实验管理端还必须烧写对应学生实验的 Xilinx 镜像。
